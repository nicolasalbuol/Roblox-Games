# Roadmap

Each update keeps the rule: nothing purchasable decides a round. Dates are targets, not promises.

## v1.0 — Launch (this repository)
Core loop, 3 arenas, 3 power-ups, bots, 34 cosmetics, daily quests/gift, 7 achievements, 100 levels,
wins board, 3 passes, 4 coin packs, analytics funnels.

## v1.1 — Polish from data (launch + 2 weeks)
- Original SFX + music pack; real screenshots/thumbnails.
- Tune `SpawnRadius`, `RoundSeconds`, `MinParticipants` from onboarding funnel (ANALYTICS.md H2–H4).
- Bot difficulty tiers matched to player level.
- Kill-cam style "who cut you" arrow for 1 s.

## v1.2 — Duo Turf (launch + 5 weeks)
- 2-player teams sharing an ink; friend auto-pairing; team leaderboard.
- Party join: friends in the same server spawn near each other.

## v1.3 — Seasons (launch + 8 weeks)
- Seasonal arena (e.g. Lantern Festival), limited-time cosmetics earnable by playing.
- Free cosmetic track with optional "Turf Club" subscription (1 exclusive cosmetic/month) — only if
  D7 and session metrics stay healthy.

## Later
- Animated emotes (requires animation uploads), victory dances on the podium.
- Bigger boards for 20-player servers; map voting.
- Spectator mode for eliminated players and private-server "tournament" settings.
